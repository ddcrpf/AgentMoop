## 0.1.0 (first public release)

- Friends by moop tag, with friend requests you accept or ignore.
- Messages, files, summaries and context packets between friends.
- Claude Code plugin: cards above the prompt, `/moop` and a mini-game while Claude works.
- MCP connector for Codex and the Claude app.
- Web app with a live inbox.
- Documentation at `/docs`.
- Self-hosting with Docker.
